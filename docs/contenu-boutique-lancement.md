# Contenu boutique - lancement

Ce document définit le contenu commercial réel à produire avant l’activation des ventes.

## Ligne éditoriale

Les produits Sphorix doivent être :

- immédiatement compréhensibles par un artisan ou un dirigeant de PME ;
- utilisables sans expertise comptable ou informatique ;
- conçus pour structurer les données, pas pour ajouter de la complexité ;
- présentés avec des exemples concrets et des captures lisibles ;
- clairement positionnés comme des outils de suivi et d’aide à la décision, pas comme une mission réglementée d’expertise comptable.

## Produit 1 - Tableau de suivi de trésorerie

### Promesse

Visualiser les entrées, les sorties et le solde mois après mois pour savoir où en est réellement la trésorerie.

### Public

Artisans, indépendants et petites entreprises qui suivent encore leur trésorerie dans plusieurs fichiers ou de manière irrégulière.

### Contenu du fichier Excel

- onglet `Mode d'emploi` ;
- onglet `Paramètres` avec catégories personnalisables ;
- onglet `Saisie` pour les entrées et sorties ;
- onglet `Suivi mensuel` ;
- onglet `Tableau de bord` ;
- calcul automatique du solde mensuel ;
- graphiques d’évolution des encaissements et décaissements ;
- exemple de données fictives clairement identifié.

### Points à montrer dans la fiche

- solde de début et de fin de mois ;
- comparaison entrées/sorties ;
- lecture des mois sensibles ;
- fonctionnement sans macro ;
- format `.xlsx` compatible Excel et importable dans LibreOffice.

### Assets à produire

- `tableau-suivi-tresorerie.xlsx` ;
- capture du tableau de bord ;
- capture de l’onglet de saisie ;
- visuel carré pour la boutique ;
- logo ou pastille Sphorix sur la couverture.

### Prix indicatif

29 € TTC, à confirmer selon le régime de TVA.

## Produit 2 - Tableau de suivi des dépenses

### Promesse

Centraliser les dépenses, les catégoriser et repérer les postes qui pèsent sur l’activité.

### Public

Entrepreneurs qui veulent mieux comprendre leurs charges sans mettre en place un logiciel de gestion complet.

### Contenu du fichier Excel

- onglet `Mode d'emploi` ;
- onglet `Catégories` ;
- onglet `Saisie des dépenses` ;
- onglet `Synthèse mensuelle` ;
- onglet `Analyse par catégorie` ;
- totaux mensuels et annuels ;
- graphiques de répartition des dépenses ;
- exemple de données fictives.

### Assets à produire

- `tableau-suivi-depenses.xlsx` ;
- capture de la synthèse ;
- capture de l’analyse par catégorie ;
- visuel boutique ;
- couverture Excel avec identité Sphorix.

### Prix indicatif

19 € TTC, à confirmer selon le régime de TVA.

## Produit 3 - Tableau de bord petite entreprise

### Promesse

Rassembler les chiffres essentiels de l’activité dans une vue simple pour préparer les décisions du mois.

### Public

TPE et petites PME qui souhaitent commencer un suivi régulier sans outil complexe.

### Contenu du fichier Excel

- onglet `Mode d'emploi` ;
- onglet `Paramètres` ;
- onglet `Données mensuelles` ;
- onglet `Indicateurs` ;
- onglet `Tableau de bord` ;
- chiffre d’affaires ;
- dépenses ;
- résultat simplifié ;
- trésorerie ;
- évolution mensuelle ;
- indicateurs personnalisables ;
- graphiques de synthèse.

### Important

Le produit doit afficher une note claire : le résultat est un indicateur de gestion simplifié et ne remplace pas les comptes annuels, les états financiers ou les conseils d’un professionnel réglementé.

### Assets à produire

- `tableau-bord-petite-entreprise.xlsx` ;
- capture du dashboard ;
- capture des indicateurs ;
- visuel boutique ;
- fiche PDF de prise en main.

### Prix indicatif

49 € TTC, à confirmer selon le régime de TVA.

Commencer avec une base claire pour enregistrer, lire et suivre les chiffres essentiels de son activité.

### Prix indicatif

79 € TTC, avec une économie visible par rapport à l’achat séparé.

## Identité visuelle des produits

Chaque produit doit partager :

- le logo Sphorix France ;
- une couleur de catégorie ;
- un titre court et lisible ;
- une mention `Outil de gestion` ou `Tableau de bord` ;
- un aperçu réel du fichier ;
- une version et une date de mise à jour ;
- une mention de licence ;
- une note de périmètre et de responsabilité.

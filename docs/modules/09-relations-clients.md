# Relations clients : checklist détaillée

Famille Clients. Relié à Commerce.

## R1. Prospects
- [ ] Fiche prospect, source, responsable, statut.
- [ ] Conversion en client du module Commerce.

## R2. Opportunités
- [ ] Pipeline par étapes, montant et probabilité.
- [ ] Création d'un devis depuis une opportunité.

## R3. Suivi
- [ ] Interactions : appels, rendez-vous, e-mails.
- [ ] Tâches et rappels.

## R4. Pilotage
- [ ] Prévisions de ventes pondérées, taux de conversion.

## R5. Interface
- [ ] Vue tableau et vue colonnes.
- [ ] Contrôle clair, sombre, mobile.
